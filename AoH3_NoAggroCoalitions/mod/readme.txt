# No Aggression Coalitions Mod
# Этот мод отключает создание коалиций против игроков за агрессивные действия.

# В Age of History 3 логика коалиций управляется через скрипты и конфигурацию игры.
# Для полного отключения коалиций за агрессию необходимо изменить файлы игры.

# Инструкция по установке:
# 1. Скопируйте содержимое папки "mod" в директорию модов игры:
#    - Windows: C:\Program Files (x86)\Steam\steamapps\common\Age of History 3\mods\NoAggroCoalitions\
#    - Linux: ~/.steam/steam/steamapps/common/Age of History 3/mods/NoAggroCoalitions/
#    - Mac: ~/Library/Application Support/Steam/steamapps/common/Age of History 3/mods/NoAggroCoalitions/

# 2. Активируйте мод в лаунчере игры.

# Примечание:
# Age of History 3 использует проприетарные форматы файлов. 
# Для полноценной работы мода может потребоваться редактирование следующих файлов игры:
# - common/coalitions.txt (или аналогичный файл конфигурации коалиций)
# - script_files/coalition_events.txt (скрипты событий коалиций)
#
# Если вы опытный пользователь, найдите эти файлы в директории игры и:
# 1. Откройте файл конфигурации коалиций
# 2. Найдите параметры, связанные с "aggression" или "aggressiveness"
# 3. Установите значения в 0 или закомментируйте соответствующие строки
#
# Пример того, что нужно искать (формат может отличаться):
# coalition_rules = {
#     aggression_threshold = 0.0  # Изменить на очень высокое значение или 0
#     enable_aggression_coalitions = no  # Изменить на no
# }

# Альтернативный метод через консоль разработчика (если доступна):
# В игре откройте консоль (~ или `) и введите команды для отправки коалиций:
# Но это временное решение, требующее повторения каждый раз.

# Для создания полноценного мода требуется:
# 1. Найти в файлах игры механизмы формирования коалиций
# 2. Переопределить их через систему модов AoH3
# 3. Протестировать изменения

# Если у вас есть доступ к документации по моддингу AoH3, 
# следуйте ей для точного переопределения механик коалиций.
